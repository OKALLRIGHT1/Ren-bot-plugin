# 音乐播放器

播放你电脑里的本地音乐。QQ 里搜歌发语音请用「QQ点歌」。

## 怎么用

本地对她说：

- `播放 春日影`
- `来首推荐` / `放你喜欢的`
- `随机来一首`
- `本地音乐 诗超绊`

只评价歌曲、不要求播放时，不要走这个插件。

## 权限

- 仅本地桌面
- QQ 不会播本地文件

## 要填的配置

打开 **插件管理 → 音乐播放器**：

| 项 | 填什么 |
| --- | --- |
| 音乐目录列表 | 一行一个文件夹路径，里面放 mp3/flac 等 |
| 红心歌单 | 关键词。说「推荐」或「你喜欢的歌」时优先从这里匹配 |

不用填 API Key。目录还是别人的盘符时，先改成你自己的音乐文件夹。

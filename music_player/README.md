# 音乐播放器

播放本地音乐。明确歌名填歌名；要推荐填「推荐」；随便听填「随机」。只评价歌曲时不要调用。

## 怎么用

- 触发词：`播放音乐`
- 类型：`react`
- 别名：`播放`、`放歌`、`来首`、`点歌`、`整首`、`听歌`、`听一首`、`放一下`、`放给我听`、`想听`、`听听`、`放` 等 17 个
- 示例：`推荐`

## 权限

可用：本地桌面。
不可用：QQ 远程、QQ 主人、QQ 他人、群聊未 @。

## 可配置项

- `music_directories`：音乐目录列表。存储音乐文件的文件夹路径。
- `favorites`：五十铃的红心歌单。当用户要求推荐或播放'你喜欢的歌'时，会优先从包含这些关键词的歌曲中选择。

# 本地第二大脑

把本地文件夹做成可搜索的知识库。先「学习」目录，再提问。

## 怎么用

- `学习这个文件夹 D:\notes`
- `在知识库里搜人设`
- 也可以：`learn ||| ./knowledge_docs`、`search ||| 某某设定`

独立的知识库窗口里可以按目录开关。

## 权限

- 本地可用
- QQ 是否开放看插件权限

## 要填的配置

打开 **插件管理 → 本地第二大脑**：

| 项 | 填什么 |
| --- | --- |
| 知识目录 | 一个或多个文件夹。可在 GUI 里选路径并开关 |
| 慢速导入 | 默认开，降低远程嵌入接口被限频的概率 |

嵌入模型走主程序的模型配置。如果知识库用了需要 Key 的远程嵌入，Key 填在 **模型与路由**，不是这张卡。

# 桌面

打开本机常用软件，以及看 CPU/内存/磁盘/GPU、调音量亮度、锁屏。

## 怎么用

打开软件（必须在信任列表里）：

- 本地或主人私聊：`打开计算器`、`启动记事本`
- 也可以让她 `open_app 画图`

看机器状态或控制：

- `现在 CPU 怎么样`、`内存占用`
- `音量调到 30`、`静音`、`亮度 +10`
- `锁屏`

不在信任列表里的程序不会直接启动。

## 权限

- 本地可用
- QQ 仅主人私聊；群聊不能远程开软件或锁屏
- 其他人不可用

## 要填的配置

打开 **插件管理 → 桌面**：

| 项 | 填什么 |
| --- | --- |
| 应用信任列表 | 一行一个 `显示名\|路径`，例如 `VS Code\|C:\...\Code.exe`。Windows 自带的可以写 `计算器\|calc.exe` |
| CPU / 内存 / 磁盘 / GPU 阈值 | 超过就提醒，百分比 |
| CPU / GPU 温度阈值 | 摄氏度 |
| 检查间隔 | 后台巡检秒数，默认 60 |

不用填 API Key。音量依赖 `pycaw`，亮度依赖 `screen_brightness_control`，缺了会在回复里提示。

# 日报

生成图片版日报，也可以查实时天气和未来几天预报。天气和早报、摸鱼日历、今日一言共用同一份 ALAPI Token。

## 怎么用

- 出日报：`/日报` 或 `/魔法日报`
- 查天气：直接问 `上海今天多少度`、`明天出门要不要带伞`、`北京这周天气怎么样`
- 也可以：`/api weather_now city=上海`、`/api weather_7d city=北京`

本地触发会把图片存到 `output/daily_reports`（可在配置里改）。QQ 里会把图片发到当前会话。定时推送按下面的时间发到你填的会话。

## 权限

- 本地可用
- QQ 主人可用；群聊可以不 @ 直接 `/日报`
- 其他人默认不能用
- 天气查询不会发给其他人

## 必须填的 API：ALAPI Token

日报的节假日、今日一言、早报，以及天气，都走 [ALAPI](https://www.alapi.cn/)。不填 Token 时这些板块会空，天气也会提示缺密钥。

**填在这里（两处写的是同一份密钥，填一处即可）：**

1. **设置 → 打开开发者模式 → 信息源**  
   页面上方「ALAPI Token」输入框，点 **保存 Token**。
2. **插件管理 → 日报 → 自定义配置 → ALAPI Token**  
   保存插件配置时会写入本机加密库。

Token 存在本机 `data/plugin_secrets.db`，对应插件触发词 `magic_daily`、键名 `api_token`。不要写进仓库里的 `config.json`，也不要发给别人。

申请地址：https://www.alapi.cn/ （注册后在控制台复制 token）。

## 其它可配置项

在 **插件管理 → 日报** 里改：

| 项 | 说明 |
| --- | --- |
| 今日新番 / 新闻 / B站热点 / 摸鱼日历 数量 | 控制各板块条数 |
| 渲染模式 | `image` 出图（需要 Playwright），`text` 只出文字 |
| 启用定时推送 | 到点自动发 |
| 定时推送时间 | `HH:MM`，例如 `08:00` |
| 定时推送目标会话 | `group:群号` 或 `private:QQ号`。只填数字时按群处理 |
| 日报标题 / 头图 / 问候风格 | 留空则跟当前角色走 |
| 板块顺序 | `moyu`、`bili_hot`、`today_anime`、`world_news`、`it_news`、`hitokoto` |

定时推送目标不要填进公开仓库。

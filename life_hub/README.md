# 生活提醒

记账、本地提醒、待办任务、番茄钟，以及 QQ 里的周期打卡提醒。以前是四个插件，现在一张卡片就能开关。

## 怎么用

本地桌面或聊天里直接说：

- 记账：`记一笔 15 块奶茶` / 让她 `list_bills`
- 本地一次性提醒：`10 分钟后提醒我关火`
- 待办：`添加任务 明天交材料`、`看看待办`、`完成任务 1`
- 番茄钟：`倒计时 25 分钟`、`开个番茄钟`

QQ 里给自己设周期提醒（只发给主人，不进群）：

```
/提醒 每周1到周5 17:20 提醒我打卡
/提醒列表
/提醒删除 打卡
```

也可以说：`提醒我 每天 08:00 起床`。

## 权限

- 本地：记账、待办、番茄钟、本地提醒可用
- QQ：周期提醒仅主人私聊；群聊需要 @
- 他人 QQ 不可用

## 要填的配置

打开 **插件管理 → 生活提醒 → 自定义配置**：

| 项 | 填什么 |
| --- | --- |
| QQ 提醒存储文件 | 默认 `data/qq_reminders.json`，一般不用改 |
| QQ 提醒轮询间隔 | 默认 20 秒 |
| QQ 提醒前缀 | 发到 QQ 的那句开头，默认 `⏰ 提醒时间到：` |

不用填 API Key。账单和待办写在程序根目录的 `userdata.db`。

如果你以前单独改过「QQ定时提醒」的存储路径，打开这张卡片确认一下路径还在。

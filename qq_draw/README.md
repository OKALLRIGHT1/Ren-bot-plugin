# QQ生图

只在 QQ 里用斜杠命令画画。图发回当前会话。本地桌面不会走这里。

## 怎么用

```
/画图 绘制一个丰川祥子在雨后的街道
/画画 一只橘猫坐在窗台上
```

消息里同时带图片时，会把图当作参考一起送去（图生图）。

## 权限

- 仅 QQ 主人；群聊需要 @
- 其他人不能画

## 要填的不是插件 API Key，是画图模型

1. **设置 → 模型与路由**  
   先给要用的模型勾选 **画图 / 图生图** 用途。
2. 同一页的任务路由里，找到 **画图**，把模型拖到右侧执行链（上方优先，失败才试下面的）。不会自动全选。
3. **插件管理 → QQ生图 → 画图模型** 也可以再排一列；留空则跟任务路由走。

连接信息（地址、Key）仍在「模型与路由」里，不要写进这个插件的 `config.json`。

## 其它可配置项

打开 **插件管理 → QQ生图**：

| 项 | 说明 |
| --- | --- |
| 默认尺寸 | 例如 `1024x1024` |
| 质量 / 风格 | 兼容 OpenAI 风格接口时可填 `standard`/`hd`、`vivid`/`natural` |
| 启用图生图 | 默认开 |
| 请求超时 | 慢速上游可调到 300 或 360 秒 |

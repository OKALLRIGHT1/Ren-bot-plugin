# QQ文件浏览

在 QQ 里用斜杠命令浏览虚拟目录 `/bot`，并把本机文件发到当前会话（尽量零拷贝）。

项目代码请用「工作区」；桌面/文档/下载请用「用户文件」。

## 怎么用

```
/文件
/ls
/cd /inbox
/get 某个文件名
/pwd
```

## 权限

- 仅 QQ 主人；群聊需要 @
- 其他人不能把你的文件要走

## 要填的配置

打开 **插件管理 → QQ文件浏览**：

| 项 | 填什么 |
| --- | --- |
| 额外挂载目录 | 一行一个 `别名\|本地路径`，例如 `qqsave\|D:\QQDownloads`。保存后 `/cd /qqsave` |
| 接收文件目录 | QQ 发给机器人的文件落到这个虚拟目录，默认 `/bot/inbox` |

不用填 API Key。只挂你愿意发到 QQ 的文件夹。

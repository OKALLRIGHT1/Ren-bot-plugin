# 表情包库

数据库版表情包系统：支持目录导入、按情绪/关键词选图、QQ 手动发送，并提供自动发送钩子。

## 怎么用

- 触发词：`meme_pack`
- 类型：`direct`
- 别名：`/表情包`、`/发表情`、`/随机表情`、`/导入表情包`、`/表情包统计`
- 示例：`/表情包 狡猾 / /导入表情包 D:\memes / /表情包统计`

## 权限

可用：本地桌面、QQ 远程、QQ 主人。
不可用：QQ 他人、群聊未 @。

## 可配置项

- `model_queue`：表情包选择模型（按顺序尝试）。从主程序模型中选择聊天用途模型。留空时跟随 default 任务路由。
- `auto_enabled`：启用自动表情包。QQ 私聊回复后，根据语气小概率追加一张表情包。
- `auto_probability`：自动发送概率。0-1，命中场景后仍按概率发送，避免刷屏。
- `auto_private_only`：仅 QQ 私聊自动发送。默认不在群聊自动发表情包。
- `llm_selector_enabled`：启用 LLM 表情包选择器。开启后会把候选表情包的描述、标签和当前对话交给模型判断是否发送以及选择哪张。
- `session_cooldown_seconds`：会话冷却秒数。同一 QQ 会话自动发送表情包的最短间隔。
- `max_candidates`：候选数量。自动选择时最多从多少张高分表情里抽取。
- `assets_dir`：素材目录。导入后图片会复制到该目录。相对路径基于项目根目录。
- `database_path`：数据库路径。表情包索引 SQLite 路径。相对路径基于项目根目录。

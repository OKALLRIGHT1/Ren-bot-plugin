# QQ去水印

QQ 中用 /去水印、/提取 或 /下载 加链接，解析公开平台视频或图集，下载后发回当前会话。明确的自然语言请求会先确认；只有链接不会触发。密钥只存在本机加密存储里。

## 怎么用

- 触发词：`qq_watermark`
- 类型：`direct`
- 别名：`/去水印`、`/提取`、`/下载`
- 示例：`/去水印 https://v.douyin.com/xxxx/`

## 权限

可用：QQ 远程、QQ 主人、QQ 他人、群聊未 @。
不可用：本地桌面。

## 可配置项

- `base_url`：解析服务地址。x-download 根地址，插件会自动请求 /v1，不会调用网页 /api。
- `api_key`：解析服务 API Key。只写入本机加密存储，不会进配置文件、日志或模型上下文。
- `request_timeout_sec`：请求超时(秒)。解析和下载共用的超时。
- `max_file_mb`：单文件上限(MB)。超过后停止下载并删除临时文件。
- `max_images`：逐张发送上限。图集张数不超过该值时逐张发送，否则改发压缩包。
- `rate_limit_per_min`：每分钟次数。同一 QQ 会话每分钟最多真正下载几次。

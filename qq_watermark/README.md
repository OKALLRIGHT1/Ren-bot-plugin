# QQ去水印

在 QQ 里用固定命令解析公开平台的视频或图集，下载后发回当前会话。

## 怎么用

```
/去水印 https://v.douyin.com/xxxx/
/提取 https://...
/下载 https://...
```

- 斜杠命令直接执行，一次只处理一个链接
- 明确说「去水印 / 下载 / 提取」并带上链接时，会先让你确认
- 只发链接、或只是随口提一句，不会下载

## 权限

- 仅 QQ；本地桌面不用这个
- 主人和其他人、群聊未 @ 默认都可以（可在插件权限里收紧）

## 必须填的 API

打开 **插件管理 → QQ去水印**：

| 项 | 填什么 |
| --- | --- |
| 解析服务地址 | 默认 `https://dl.tomori.de5.net/`，插件会请求 `/v1`，不会走网页 `/api` |
| 解析服务 API Key | 解析服务给你的密钥 |

密钥只写入本机加密存储，不会进配置文件、日志或模型上下文。不填 Key 时解析会失败。

## 其它可配置项

| 项 | 说明 |
| --- | --- |
| 单文件上限 | 超过就停并删临时文件，默认 80 MB |
| 逐张发送上限 | 图集张数不超过该值时逐张发，否则改发压缩包 |
| 每分钟次数 | 同一 QQ 会话每分钟最多真正下载几次 |

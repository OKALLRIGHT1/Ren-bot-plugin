# 主人控制台

主人侧常用控制：功能帮助、远程重启、Agent 自检、副脑任务、模型调用摘要。以前是五张卡片，权限按动作分开，不会因为开了 `/帮助` 就让别人 `/重启`。

## 怎么用

| 你想做的事 | 怎么说 |
| --- | --- |
| 看现在有哪些 QQ 功能 | `/帮助`、`/功能`、`你会什么` |
| 按分类查 | `/帮助 生图`、`/帮助 提醒`、`/帮助 文件` |
| 重启主程序 | `/重启`、`/远程重启`、`/restart` |
| Agent 自检 / 工具列表 / 代码在哪 | `/agent 自检`、`agent 工具列表`、`代码在哪` |
| 看副脑委托 | `副脑任务`、`副脑任务 <任务ID>` |
| 模型调用好不好使 | 说 `模型监控` 或 `成本监控` |

## 权限（按动作）

- **`/帮助`**：本地、QQ 主人、其他 QQ、群聊未 @ 都可以
- **`/重启`**：仅本地或 QQ 主人。其他人说了会被拒绝
- **Agent 自检 / 副脑任务 / 模型监控**：仅本地或 QQ 主人

群聊里重启仍然要求是主人；不要把重启理解成「桌面状态检查」，那是「桌面」插件的事。

## 要填的配置

打开 **插件管理 → 主人控制台**：

| 项 | 填什么 |
| --- | --- |
| 帮助里显示已禁用插件 | 默认关。打开后 `/帮助` 也会列出你关掉的插件 |

不用填 API Key。

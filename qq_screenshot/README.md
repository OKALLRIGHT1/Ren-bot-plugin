# QQ远程截图

在 QQ 中直接把当前电脑屏幕截图回发给主人。

## 怎么用

- 触发词：`qq截图`
- 类型：`direct`
- 别名：`截图发我`、`截图发给我`、`截个图发我`、`截个图发给我`、`发个截图`、`发张截图`、`发截图给我`、`把截图发我`、`把截图发给我`、`把屏幕发我`、`发屏幕给我`、`把屏幕截图发我` 等 19 个
- 示例：`截图发我`

## 权限

可用：QQ 远程、QQ 主人。
不可用：本地桌面、QQ 他人、群聊未 @。

## 可配置项

- `capture_target`：默认截图范围。可选主屏、全部屏幕，或固定抓取第 N 块屏幕。聊天里也能临时说“主屏 / 全部屏 / 第2屏”。
- `monitor_index`：默认屏幕序号。当默认截图范围为 monitor 时生效，1 表示第一块屏幕。
- `include_window_title`：附带当前窗口标题。回发截图时，额外附上一行当前活跃窗口标题。

# QQ定时提醒

在 QQ 中创建仅发给自己的定时提醒，支持工作日、每天等周期提醒。

## 怎么用

- 触发词：`qq提醒`
- 类型：`direct`
- 别名：`/提醒`、`/提醒列表`、`/提醒删除`、`/提醒测试`、`提醒我`、`打卡提醒`、`定时提醒`、`提醒`
- 示例：`/提醒 每周1到周5 17:20 提醒我打卡`

## 权限

可用：QQ 远程、QQ 主人。
不可用：本地桌面、QQ 他人、群聊未 @。

## 可配置项

- `storage_path`：提醒存储文件。保存提醒任务的 JSON 文件路径。
- `scan_interval_sec`：轮询间隔(秒)。后台检查提醒是否到点的间隔。
- `default_reminder_prefix`：提醒前缀。发送到 QQ 的提醒消息前缀。

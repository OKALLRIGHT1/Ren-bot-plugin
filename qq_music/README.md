# QQ点歌

在 QQ 里搜歌，并以语音发回。默认先搜 QQ 音乐，没有再试网易云。

这和「音乐播放器」不是一回事：那个是播你电脑里的本地文件；这个是上网搜歌发到 QQ。

## 怎么用

QQ 里对她说：

- `点歌 晴天`
- `来首歌 春日影`
- `QQ点歌 蓝春日影`

本地桌面不会走这个插件。

## 权限

- 仅 QQ 主人；群聊需要 @
- 其他人不能点

## 必须填的 API

打开 **插件管理 → QQ点歌**：

| 项 | 填什么 |
| --- | --- |
| API Base URL | 默认 `https://gateway.karpov.cn`，一般不用改 |
| API Key | 网关密钥。也可设环境变量 `QQMUSIC_API_KEY` |
| Session Cookie | 网关如果要网页登录态，把完整 Cookie 贴这里，例如 `sid=...; csrf_token=...` |

密钥存在本机加密库，不要写进 `config.json`。不填 Key 时搜歌会失败。

## 其它可配置项

| 项 | 说明 |
| --- | --- |
| 默认音质 | 建议 `MP3_320`，QQ 语音比较稳 |
| 搜索源顺序 | 逗号分隔，默认 `qqmusic,netease` |
| QQ 失败回退网易云 | 默认开 |
| 语音后补一句点评 | 默认开；点评模型在「点歌点评模型」队列，留空跟主程序聊天路由 |

本地想放自己的歌，用 **插件管理 → 音乐播放器**，说 `播放 春日影` 或 `来首本地音乐`。

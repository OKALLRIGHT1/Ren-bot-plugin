# 主人跨通道近史

主人按需查「另一侧」最近说了什么：桌面聊的摘要，或 QQ 聊的摘要。默认两边会话仍隔离，不会自动混进提示词。

## 怎么用

- `/桥接 desktop`
- `/跨通道 qq 刚才在干嘛`
- `desktop ||| 刚才在干嘛`

## 权限

- 本地可用
- QQ 仅主人
- 其他人不可用

## 要填的配置

打开 **插件管理 → 主人跨通道近史**：

| 项 | 说明 |
| --- | --- |
| max_items | 最多带几条近史，默认 8 |
| max_chars | 摘要最长字符，默认 1200 |

不用填 API Key。
